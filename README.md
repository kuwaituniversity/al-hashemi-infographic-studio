🌟 About the Project | نبذة عن المشروع

English

Al-Hashemi Infographic Studio is an educational plugin for Claude AI designed to help students, educators, researchers, and content creators transform ideas, documents, and information into professional static and animated infographics.

The project combines artificial intelligence, visual storytelling, motion graphics, and interactive design to make information easier to understand and communicate.

العربية

استوديو الهاشمي للإنفوجرافيك هو إضافة تعليمية لمنصة Claude AI، تهدف إلى تمكين الطلبة وأعضاء هيئة التدريس والباحثين وصنّاع المحتوى من تحويل الأفكار والمعلومات والملفات إلى إنفوجرافيك احترافي ثابت أو متحرك.

يجمع المشروع بين الذكاء الاصطناعي والسرد البصري والرسوم المتحركة والتصميم التفاعلي، لتقديم المعلومات بأسلوب جذاب وسهل الفهم.

🚀 Features | المميزات

* 🎨 Professional static infographics — إنشاء إنفوجرافيك ثابت.
* 🎬 Animated and interactive infographics — إنشاء إنفوجرافيك متحرك وتفاعلي.
* 🌍 Arabic and English support — دعم اللغتين العربية والإنجليزية.
* 📱 Multiple aspect ratios: 9:16, 16:9, and 1:1.
* 📊 Data visualization and animated charts.
* 🎓 Educational presentations and visual explainers.
* 📄 Transform uploaded documents into visual content.
* 🎙️ Optional AI voice-over through a compatible user-connected service.
* 🎵 Optional AI-generated background music through a compatible user-connected service.
* 🔊 Support for user-provided music and narration files.
* ▶️ Interactive playback controls when supported.

Important: Automatic music and voice generation require a compatible audio service connected by the individual user. These capabilities are not guaranteed by installing the plugin alone.

📥 Installation | طريقة التثبيت

English

1. Open Claude.
2. Navigate to Customize → Plugins.
3. Select Add and look for an option to add a plugin marketplace from GitHub.
4. Use the repository:
    kuwaituniversity/al-hashemi-infographic-studio
5. Follow Claude’s installation instructions.
6. Enable Al-Hashemi Infographic Studio if prompted.

Note: Available installation options may vary by Claude version, account, and workspace permissions.

العربية

1. افتح منصة Claude.
2. انتقل إلى Customize → Plugins.
3. اضغط Add وابحث عن خيار إضافة مصدر للإضافات من GitHub.
4. أدخل عنوان المستودع:
    kuwaituniversity/al-hashemi-infographic-studio
5. اتبع خطوات التثبيت التي تظهر في Claude.
6. فعّل إضافة Al-Hashemi Infographic Studio إذا طُلب منك ذلك.

ملاحظة: قد تختلف خيارات التثبيت حسب نوع حساب Claude وصلاحيات المستخدم.

🎬 Example Prompts | أمثلة للاستخدام

Example 1: Educational Infographic

Create a professional Arabic infographic explaining the differences between news and opinion. Use clear typography, relevant icons, and a visually balanced layout suitable for university students.

Example 2: Animated Stop Motion Tutorial

Create a professional animated Arabic infographic explaining how to produce a coffee advertisement using Stop Motion Studio. Use a vertical 9:16 layout, animated illustrations, smooth transitions, and interactive playback controls.

Example 3: Product Advertisement

Create an animated infographic advertising a natural lemon-mint beverage. Use professional motion graphics, engaging product information, and a vertical layout suitable for Instagram Reels.

Example 4: Research Visualization

Transform the uploaded research document into an academic infographic highlighting the research objectives, methodology, key findings, and conclusions. Do not invent information or statistics.

🎵 Music & Voice-over | الموسيقى والتعليق الصوتي

Users may choose between three options for background music:

1. Generate music using their own compatible AI audio service.
2. Upload an existing audio file.
3. Create the infographic without music.

For narration, users may:

1. Generate AI voice-over through their own connected service.
2. Upload a recorded voice-over.
3. Generate a narration script without audio.
4. Disable narration.

🔐 Privacy and API Security

* The developer’s personal ElevenLabs account is not provided for student use.
* The plugin does not include shared API keys.
* Users are responsible for authorizing their own audio-generation services.
* API credentials must not be entered into public repositories or embedded in generated HTML.
* Audio generation may involve third-party usage limits or charges.
* Users should ensure they have appropriate rights to any uploaded audio.

📤 Export and Limitations | التصدير والقيود

Animated infographics can be created as interactive HTML content when supported by Claude Artifacts.

Exporting a finished video in MP4 format may require additional screen recording, rendering, or video production tools.

The plugin’s instructions alone do not provide a built-in audio-generation engine or guarantee access to third-party services.
