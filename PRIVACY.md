Privacy Policy

Al-Hashemi Infographic Studio

Last updated: October 24, 2026

1. Introduction

Al-Hashemi Infographic Studio is an educational plugin designed to help users create professional static and animated infographics within Claude.

The plugin is developed by Dr. Mahmood Abdulnabi Al-Hashemi.

2. Information Processing

The plugin may process information voluntarily provided by users, including:

* Educational topics and project descriptions.
* Uploaded documents and research materials.
* Text, images, and data used to create infographics.
* User-provided audio files and narration scripts.

Uploaded materials may contain personal information. Users should avoid uploading sensitive information unless necessary and appropriately authorized.

3. Data Storage

Al-Hashemi Infographic Studio does not operate an independent server or database for collecting or storing user information.

The plugin developer does not independently receive or retain users’ uploaded materials through the plugin.

Information processed within Claude remains subject to the applicable privacy policies and data-handling practices of the Claude platform.

4. Third-Party Services

The plugin does not independently transmit user information to ElevenLabs or other external audio-generation services.

No developer-owned ElevenLabs API keys or accounts are provided to users.

The plugin may assist users in preparing narration scripts and incorporating audio files they supply.

5. AI-Generated Content

The plugin assists users in creating educational and creative visual content.

Users are responsible for reviewing generated materials for accuracy, copyright compliance, and appropriate use.

6. Security

The plugin does not require users to provide passwords or API keys belonging to the developer.

Users should not include confidential credentials in uploaded documents or prompts.

7. Children

The plugin is primarily intended for adult students, educators, researchers, and content creators. It is not specifically directed toward children under 18.

8. Changes to This Policy

This policy may be updated to reflect changes in the plugin’s functionality or data-handling practices.
